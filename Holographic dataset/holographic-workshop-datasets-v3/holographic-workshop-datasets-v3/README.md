# Holographic Workshop Dataset Pack V3

Expanded foundation for the standalone Holographic Workshop Agent.

## Included
- 1,000 conceptual object/component records with stable IDs and asset references.
- 250 system recipes across physics, electronics, mechanical engineering, robotics, energy, and more.
- 100 natural-language command-routing examples.
- 10 deterministic simulation schemas.
- Starter material-property registry.
- Unit/dimension registry.
- 1,000-row asset registry with provenance/license placeholders.
- Manifest for ingestion validation.

## Recommended production pipeline
1. Validate JSON against schemas before ingestion.
2. Index object/system descriptions for retrieval.
3. Keep simulation equations deterministic and execute them in a sandboxed engine.
4. Replace placeholder asset references only with assets whose licensing/provenance is verified.
5. Store dataset version + provenance with every generated workspace.

## Important
The values and systems are conceptual starter data. They are not engineering certification, safety validation, medical advice, or production design specifications.
