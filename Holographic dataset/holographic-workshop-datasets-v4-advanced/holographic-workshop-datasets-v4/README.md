# Holographic Workshop Dataset Pack V4 — Advanced Domains

This expansion adds advanced educational/research-oriented knowledge structures across chemistry, nanotechnology, robotics, exosuits, antimatter/high-energy physics, quantum science, space, fusion, advanced materials, biotechnology, Earth science, and advanced computing.

## Included
- elements_118.json — all 118 chemical elements
- elements_index.csv — element lookup table
- advanced_chemistry.json — advanced chemistry topic schemas
- nanomaterials_100.json — nanoscale material/particle concepts
- advanced_robotics_100.json — advanced robot classes/capability schemas
- exosuits_10.json — non-weaponized exosuit concepts
- antimatter_concepts.json — high-level antimatter/annihilation concepts
- advanced_domains.json — cross-domain advanced concepts
- cross_domain_scenarios.json — Workshop exploration scenarios

## Data provenance
For production scientific values, prefer authoritative sources such as IUPAC and NIST and store source/version metadata with every imported record.

## Safety and scientific integrity
These datasets are intended for visualization, education, retrieval, and conceptual simulation. They deliberately do not provide operational instructions for hazardous chemistry, weapon construction, harmful biological engineering, or weaponized armor systems. Advanced/high-energy records are conceptual and should not be treated as experimental procedures or validated engineering specifications.
