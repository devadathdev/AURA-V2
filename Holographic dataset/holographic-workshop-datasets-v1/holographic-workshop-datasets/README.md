# Holographic Workshop Dataset Pack

Starter datasets for the standalone Holographic Workshop Agent.

## Files
- workshop_objects.json — conceptual object/component catalog
- educational_systems.json — systems and learning objectives
- simulation_parameters.json — safe starter parameters for interactive demos
- workshop_commands.json — intent/examples for command routing
- asset_manifest.csv — planned 3D asset registry

## Important
These are starter/conceptual datasets, not validated engineering specifications.
Use them for visualization, education, prototyping, and agent testing.
