# Code Analysis

Native Aura core skill for analyzing workspace source code, counting lines of code, assessing project structure, and identifying entry points.

## Capabilities
- Inspects workspace files safely within sandboxed boundaries.
- Summarizes project language breakdown (JavaScript, TypeScript, Python, etc.).
- Measures file sizes and counts.
